4. ПОРЯДОК ВЫПОЛНЕНИЯ (общий для всех вариантов)
Часть 1. Серверная часть
Установите зависимости: npm install socket.io.
Создайте HTTP-сервер с Express и прикрепите Socket.IO:

javascript
const http = require('http');
const express = require('express');
const { Server } = require('socket.io');

const app = express();
const server = http.createServer(app);
const io = new Server(server, { cors: { origin: '*' } });

io.on('connection', (socket) => {
  console.log('User connected', socket.id);
  // обработка ваших событий
  socket.on('chat message', (msg) => {
    io.emit('chat message', msg);
  });
  socket.on('disconnect', () => console.log('User disconnected'));
});
server.listen(3000);
Часть 2. Клиентская часть (React)
Установите клиентскую библиотеку: npm install socket.io-client.
В React-компоненте создайте соединение:

 
import io from 'socket.io-client';
const socket = io('http://localhost:3000');
Отправляйте сообщения: socket.emit('chat message', text).
Получайте сообщения: socket.on('chat message', (msg) => {...}).

8. ПРИМЕЧАНИЯ
Работа выполняется индивидуально.
Socket.IO автоматически использует WebSocket, но при необходимости переключается на long polling – это удобно для учебных проектов.
Для хранения истории сообщений (если требуется) рекомендуется использовать MongoDB Atlas (бесплатный кластер M0) – он доступен в Беларуси.
Клиент можно реализовать в виде отдельного React-компонента в вашем основном проекте (ветка 27). Или, если не хотите смешивать, создать отдельную ветку 27-websocket с упрощённым клиентом для демонстрации.
